📌Project Overview
The Tourist Guide Portal is a web-based application developed to help tourists explore famous tourist destinations, create accounts, and book tours online. The system provides a simple and user-friendly interface where users can view tourist place information and submit tour booking requests.
This project demonstrates basic web development concepts along with cloud deployment using GitHub Pages, showing how static web applications can be hosted on cloud platforms.
🚀 Features
User Registration
User Login
Home Page
Tourist Places Information
Tour Booking Form
Responsive User Interface
Online Website Deployment using GitHub Pages
